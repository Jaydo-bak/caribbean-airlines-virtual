# Caribbean Airlines Virtual Website

## Files
- index.html — website structure/content
- styles.css — responsive visual design
- script.js — navigation, counters and community button behavior

## vAMSYS
The Pilot Login button is connected to the Caribbean Airlines Virtual vAMSYS login:
https://vamsys.io/login/caribbean

Replace the registration URL if your vAMSYS installation uses a different registration endpoint.

## Customize
1. Replace the CA circle with your official VA logo if desired.
2. Replace the Discord placeholder in `index.html` with your official Discord invite.
3. Update statistics, routes, fleet and operational information to match your VA.
4. Upload the three files to your web host.
